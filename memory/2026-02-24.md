## Key Decisions

- Selection persists across filter changes (set lives on widget, checkbox re-derived in `_apply_filter`).
- Row keys = label IDs for stable `update_cell()` without full redraws.
- `RowSelected` (not `RowHighlighted`) avoids toggling on arrow key navigation.
- `Static.renderable` doesn't exist in this Textual version — tests check `_selected_ids` set directly.

## Bug Fix — Invisible Action Bar Buttons (round 3, resolved)

- **Root cause (actual)**: The `Static("0 selected")` widget defaults to `width: 1fr` in a Horizontal container, expanding to fill the full container width and pushing both buttons offscreen (clipped by `overflow: hidden`). The working `.button-row` in `operations.py` only has `Button` children which have `width: auto` in their DEFAULT_CSS.
- **Fix**: Added `width: auto` to `#labels-selection-count` so the Static shrink-wraps its text. Restored `layout: horizontal` for explicitness.
- All 17 tests pass after fix.
