# 2026-03-05 — Incremental Sync TUI Support

## Changes
- **Operations widget**: Added `Checkbox("Full Sync", id="cb-full-sync")` below the params grid. `get_params()` now includes `force_full_sync` key.
- **app.py**: `force_full_sync` auto-propagates to `ingestor.run()` via `**run_params` spread. Explicitly added to `ingestor.run_discovery()` call.
- **db_reader.py**: Added `get_sync_state()` — queries `sync_state` table with LEFT JOIN to `labels`. Handles missing table via `except OperationalError`.
- **dashboard.py**: Added "Sync State" section between "Last Fetch Run" and "Configuration". Shows label name, history_id, and last update timestamp per label.
- **Tests**: 3 new app tests (checkbox presence, default param, toggle param). 3 new DB reader tests (missing table, with data, LEFT JOIN null label_name).
